Why key beats BPM

Two tracks at an identical tempo still sound wrong if the keys fight. That's the amateur mistake — beatmatch first, wonder why it's sour. This engine ranks harmony first and tempo second, because a few BPM of drift is trivial to absorb and a key clash is not fixable at all.

Four commands

Built only on what's already installed — ffmpeg, aubio, rubberband, sox. No accounts, no subscriptions, no cloud.

xen-mashup analyze track.mp3

BPM, key, Camelot code and duration for one file.

xen-mashup scan ~/Music

Walks the folder, analyzes everything, caches the library to JSON.

xen-mashup match --bpm 6

Ranks every compatible pair in the library. Harmony first, tempo gap second.

xen-mashup blend a.mp3 b.mp3 out.wav

Stretches B to A's tempo with rubberband — pitch preserved — then mixes.
